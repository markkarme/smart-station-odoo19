Smart Station REST API

Comprehensive API for Smart Station Portal Features

This module provides REST API endpoints for external applications (React, Vue, Angular, Mobile apps) to integrate with Smart Station portal features.

Features

Authentication

  • JWT-based authentication
  • Access tokens (1 hour)
  • Refresh tokens (30 days)
  • Device management

Attendance Management

  • GPS-based check-in/out
  • Location validation
  • Attendance history
  • Statistics and reports

HR Management

  • Time off requests
  • Leave allocations
  • General requests
  • Attendance adjustments

Student Management

  • Student attendance
  • Exams and grades
  • Fee plans
  • Violations tracking

API Endpoints

Authentication

  • POST /api/v1/auth/login - Login with credentials
  • POST /api/v1/auth/refresh - Refresh access token
  • POST /api/v1/auth/logout - Logout and invalidate tokens
  • GET /api/v1/auth/me - Get current user info

Attendance

  • POST /api/v1/attendance/check-location - Validate GPS location
  • POST /api/v1/attendance/submit - Submit attendance
  • GET /api/v1/attendance/me - Get my attendance
  • GET /api/v1/attendance/stats - Get statistics

Leaves

  • GET /api/v1/leaves/types - Get available leave types
  • GET /api/v1/leaves/me - Get my leaves
  • POST /api/v1/leaves - Create leave request
  • POST /api/v1/leaves/{id}/cancel - Cancel leave

Usage

1. Install the module

Install this module along with attendance_location_portal

2. Login from external app

POST /api/v1/auth/login
Content-Type: application/json

{
  "login": "user@example.com",
  "password": "password123"
}

3. Use access token

GET /api/v1/attendance/me
Authorization: Bearer your_access_token_here
