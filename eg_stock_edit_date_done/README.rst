Stock Picking Edit Done Date
============================

The **Stock Picking Edit Done Date** module allows users to change the "done" date on stock picking records. This provides flexibility in adjusting the date when editing stock picking details, enabling better management of inventory transactions.

Highlights
----------
- **Edit the "Done" Date**: Allows users to modify the "done" date for stock picking records.
- **User Access Control**: Set access rights for users to update the effective date.
- **Flexible Date Management**: Change the "done" date when editing stock picking entries.

Key Features
------------
1. **Users Form View**:
   - Allows setting access rights for updating the effective date.

2. **Delivery Order Form View**:
   - In the delivery orders form view, users can find an "Update Effective Date" button that opens a wizard for editing the effective date.
   - Navigation: *Inventory → Operations → Transfers → Delivery*.

3. **Stock Picking Form View with Edited Date**:
   - Displays the stock picking form with the updated effective date after editing.
